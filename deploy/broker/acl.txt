# Quem pode escrever e ler o que.
#
# Na 8883 o usuario nao vem de senha: vem do CN do certificado do cliente
# (use_identity_as_username no mosquitto.conf). O certificado emitido para a
# usina 'acopiara' tem CN=acopiara, entao para o broker ele E o usuario
# acopiara. Nao ha lista de senhas para manter.
#
# Regra pratica: gateway escreve em dev/read, le em dev/write. O servidor faz
# o oposto. Nao ha usuario que faca os dois.

# --------------------------------------------------------------------------
# Gateways de usina
# --------------------------------------------------------------------------
# Um certificado so' para a frota, CN=gateway, embutido no .exe. Todas as 200
# usinas chegam como o mesmo usuario, entao a regra e uma so'.
user gateway
topic write dev/read/UFV/#
topic read  dev/write/UFV/#

# O preco de um certificado unico: nao ha separacao entre usinas. Quem extrair
# a chave do .exe publica telemetria no nome de qualquer uma e recebe o comando
# de todas. Para separar, o caminho e um certificado por usina (CN = slug) com
# use_identity_as_username e estas duas linhas no lugar das de cima:
#     pattern write dev/read/UFV/%u/#
#     pattern read  dev/write/UFV/%u/#
# Testado e funcionando, inclusive o isolamento. Ficou de fora por decisao de
# operacao: um binario so' para a frota, sem par para emitir e distribuir.
#
# Cuidado ao conferir ACL a mao: o mosquitto ACEITA assinatura com curinga em
# topico proibido e devolve SUBACK positivo - ele filtra na ENTREGA, nao no
# SUBSCRIBE. "Consegui assinar" nao prova buraco nenhum.

# --------------------------------------------------------------------------
# Lado servidor: consome telemetria de todas e envia comando
# --------------------------------------------------------------------------
user servidor
topic read  dev/read/UFV/#
topic write dev/write/UFV/#

# --------------------------------------------------------------------------
# Somente leitura, para depurar sem poder mexer em nada
# --------------------------------------------------------------------------
user observador
topic read dev/read/UFV/#
